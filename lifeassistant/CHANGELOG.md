# 生活助手更新日志

## [1.0.0] - 2024-02-15

### 🎉 首发版本

生活助手正式上线！

### ✨ 新功能

- **待办事项管理**
  - 创建、编辑、删除待办事项
  - 支持标题和详细描述
  - 按提醒时间自动排序

- **智能提醒系统**
  - 到期自动推送本地通知
  - 可配置重复提醒间隔（默认5分钟）
  - 持续提醒直到用户确认

- **喜庆主题界面**
  - 春节红色主题设计
  - 金色装饰元素
  - 流畅的动画效果

- **数据管理**
  - 本地数据库存储
  - 应用设置页面
  - 一键清除所有数据
  - 重置数据库功能

- **跨平台支持**
  - 支持 Android 5.0+ 系统
  - 兼容华为 HarmonyOS
  - 适配小米、OPPO、vivo 等主流机型
  - Web 端支持

### 🔧 技术特性

- 使用 Flutter 框架开发
- SQLite 本地数据库
- 本地通知插件
- Material Design 3 设计规范

### 📝 已知问题

- 无

### 🔒 隐私安全

- 所有数据本地存储，不上传云端
- 无需注册登录
- 应用卸载后数据自动清除
